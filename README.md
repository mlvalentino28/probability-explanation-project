# Probabilium

**Probabilium** is a simple educational website that explains high-school probability concepts through concise definitions, formulas, visual cards, and worked examples. It was created for students willing to learn probability.

## Topics Covered

The website presents the following topics:

1. Probability basics
2. Probability of an event
3. Probability of a complement
4. Independent events
5. Conditional probability
6. Mutually exclusive events
7. Non-mutually exclusive events

It also includes a short comprehension test hosted on Wayground.

## Project Purpose

The project aims to:

- Summarize probability material from the *Modul Peluang XI Kolese Kanisius*
- Present formulas and concepts in an easy-to-read format
- Provide examples and solutions for each topic
- Make probability lessons more engaging and accessible for students
- Save study time through a focused, single-page presentation

## Technologies

- HTML5
- CSS3

No frameworks or build tools are required.

## Getting Started

### View locally

1. Clone the repository:

```bash
git clone https://github.com/mlvalentino28/probability-explanation-project.git
```

2. Enter the project directory:

```bash
cd probability-explanation-project
```

3. Open `index.html` in a web browser.

The site can also be run with a local server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

### View on GitHub Pages

Once GitHub Pages is enabled for the repository, the site will be available at:

```text
https://mlvalentino28.github.io/probability-explanation-project/
```
